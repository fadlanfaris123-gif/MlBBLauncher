# MLBBLauncher

Aplikasi Android sederhana untuk menyimpan Device ID secara lokal dan membuka Mobile Legends: Bang Bang.

## Fitur
- Menyimpan Device ID di perangkat.
- Tombol untuk membuka Mobile Legends.
- Tampilan sederhana dan ringan.

## Catatan
- Device ID hanya disimpan di perangkat.
- Aplikasi ini tidak digunakan untuk login atau melewati keamanan akun Moonton.
- Pastikan Mobile Legends sudah terpasang di perangkat.

## Build APK
APK dibuat otomatis melalui GitHub Actions.

Setelah proses build selesai:
1. Buka tab **Actions**.
2. Pilih proses build yang berhasil.
3. Scroll ke bagian **Artifacts**.
4. Download APK yang tersedia.
